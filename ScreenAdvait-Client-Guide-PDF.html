📌 Overview

What is ScreenAdvait?

A simple tool that automatically takes screenshots of your employees' computers and stores them securely for you to review anytime.

🖥️

Desktop App

A small app installed on each employee's computer. It runs silently in the background — employees won't see it.

📸

Auto Screenshots

The app automatically captures the employee's screen at intervals you choose (every 5, 15, or 30 minutes).

🌐

Web Portal

View all captured screenshots from anywhere using your secure web dashboard. No software needed — just a browser.

⚠️ Security — Chrome

If Chrome Blocks the Download

Chrome may show "Virus detected" or "Failed — Blocked". This is a false alarm.

  • 1
    Open Chrome Downloads PagePress Ctrl + J or type chrome://downloads in the address bar.
  • 2
    Find the Blocked FileLook for "ScreenAdvait-Enterprise-Desktop-Setup" with a "Blocked" or "Virus detected" label.
  • 3
    Click "Keep" or "Keep dangerous file"Click the option to keep the file. If prompted again, confirm by clicking "Keep anyway".
ℹ️
Why? The app captures screenshots which looks similar to monitoring tools. Chrome is cautious with new apps. The app is 100% safe.

🛡️ Security — Windows Defender

If Windows Blocks the Installer

"Operation did not complete because the file contains a virus." — This is a false alarm.

  • 1
    Open Windows SecurityPress the Windows key, type "Windows Security", and open it.
  • 2
    Go to Protection HistoryClick "Virus & threat protection" → click "Protection history".
  • 3
    Find & Allow the FileFind "ScreenAdvait" entry → click "Actions" → select "Allow on device".
  • 4
    Run the Installer AgainDouble-click the installer. It will now install successfully without any warnings.

🛡️ Alternative Method

Add Exclusion Before Installing

If the above steps don't work, add an exclusion first.

  • 1
    Open Windows SecurityPress the Windows key → type "Windows Security" → open it.
  • 2
    Go to ExclusionsClick "Virus & threat protection" → "Manage settings" → scroll to "Exclusions" → "Add or remove exclusions".
  • 3
    Add the Installer FileClick "+ Add an exclusion" → choose "File" → select the ScreenAdvait-Enterprise-Desktop-Setup.exe file.
  • 4
    Run the InstallerNow double-click the installer. It will run without being blocked.
✅
This is a one-time step. Once the app is installed, it runs without any further issues.

📊 Monitoring

Device Status Indicators

Track which employees are actively being monitored.

StatusWhat It MeansWhat You Should Do
Active The employee's computer is online and the app is running. Screenshots are being captured. Nothing — everything is working fine. ✅
Disconnected The computer has been offline for more than 15 minutes. App may be stopped or PC shut down. Check if the PC is turned on and connected to internet. If app was deleted, reinstall it.
Never Connected Employee was created but the desktop app has never been installed or logged in. Install the desktop app on the employee's computer and login with their credentials.
🚨
If an employee deletes the app: Their status changes to 🔴 Disconnected after 15 minutes. You'll see this on your portal.
